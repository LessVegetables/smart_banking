# Мок-сервис источников

Играет все источники SPEC §5 по данным синтетического мира (`apps/world/`): внутренние счета и карточку клиента, ЕГРЮЛ / ЕГРИП, ФНС (+ГИР БО), БКИ, ФССП, арбитраж и Федресурс, 115-ФЗ. `# MOCK:` никаких обращений к настоящим системам нет.

Сервис только изображает источник: отдаёт ответ с задержкой или падает так, как падает настоящая интеграция. Конверт `SourceResponse` (статус, число попыток, задержка, ошибка), таймауты и повторы — работа адаптеров (T07).

## Как пользоваться

```python
from apps.sources import service_from_env

service = service_from_env()  # мир и настройки из переменных окружения
payload = await service.fetch('bki', '5406000001')  # BkiPayload
```

`fetch(source, inn)` — асинхронный, поэтому источники можно опрашивать параллельно (`asyncio.gather`). Он возвращает `payload` своего контракта (`AccountsPayload`, `EgrulPayload`, …) или бросает исключение:

| Исключение | Когда | Что делает сервис |
|---|---|---|
| `SourceUnavailable` | источник ответил ошибкой | ждёт обычную задержку и падает |
| `SourceTimeout` | источник завис | ждёт `hang_seconds` (15 с — дольше таймаута адаптера 10 с, SPEC §6) и падает. Адаптер должен сам оборвать ожидание, например `asyncio.wait_for` |
| `SourceNotFound` | в мире нет компании с таким ИНН | ждёт обычную задержку и падает |

Для разовых выборок без задержек (например, подбор персон в T12) ответ источника можно взять напрямую: `payload(company, source)`.

### HTTP

`apps/sources/router.py` — тот же сервис по HTTP: `GET /mock-sources/{source}/{inn}`. Ответы: 200 — payload, 404 — неизвестный ИНН или источник, который сервис не играет, 503 — ошибка, 504 — таймаут (после зависания). Роутер **пока никуда не подключён** (см. «Что нужно следующим задачам»):

```python
from apps.sources import service_from_env
from apps.sources.router import make_router

app.include_router(make_router(service_from_env))  # мир строится при первом запросе
```

## Откуда берётся мир

`load_world()` читает мир из `WORLD_DIR` (по умолчанию `apps/world/out`), если его записала текущая версия генератора. Иначе — или если папки нет — строит мир заново по `WORLD_SEED`, `WORLD_N` и `WORLD_AS_OF` (по умолчанию 42, 5000 и 2026-10-01). Мир по умолчанию строится около 5 секунд.

## Настройки

Все переменные необязательные. Значения по умолчанию подходят для демо: задержки реалистичные, случайных сбоев нет.

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `MOCK_SOURCES_LATENCY_SCALE` | `1` | Множитель задержек. `0` — ответ сразу (тесты), `0.1` — быстрое демо |
| `MOCK_SOURCES_FAILURES` | `off` | `on` — случайные сбои с частотами из таблицы ниже |
| `MOCK_SOURCES_HANG_SECONDS` | `15` | Сколько висит источник при таймауте. Множитель задержек на него не действует |
| `MOCK_SOURCES_SCENARIOS` | — | Принудительные исходы по ИНН, JSON: `{"<ИНН>": {"<источник>": "<сценарий>"}}` |
| `WORLD_DIR`, `WORLD_SEED`, `WORLD_N`, `WORLD_AS_OF` | см. выше | Какой мир играть |

Задержки и частоты сбоев по источникам (`DEFAULT_BEHAVIOUR` в `service.py`). `# MOCK:` задержки взяты в диапазоне примеров из `tests/fixtures/sources/`, частоты сбоев — оценка.

| Источник | Медиана задержки | Ошибка | Таймаут |
|---|---|---|---|
| Счета (`accounts`) | 140 мс | — | — |
| Карточка клиента (`client_card`) | 60 мс | — | — |
| ЕГРЮЛ / ЕГРИП (`egrul`) | 800 мс | 2% | 1% |
| ФНС (`fns`) | 1,8 с | 3% | 2% |
| БКИ (`bki`) | 2,4 с | 2% | 2% |
| ФССП (`fssp`) | 1,1 с | 5% | 5% |
| Арбитраж и Федресурс (`arbitration`) | 1,3 с | 3% | 3% |
| 115-ФЗ (`aml`) | 400 мс | 1% | 1% |

Задержка — логнормальная вокруг медианы (σ = 0,35). Внутренние источники не бывают недоступны (SPEC §5), поэтому случайные сбои их не касаются.

### Сценарии

Сценарий задаёт исход для одного ИНН и одного источника и работает всегда, даже при `MOCK_SOURCES_FAILURES=off`:

- `timeout` / `error` — каждый вызов;
- `timeout:N` / `error:N` — первые N вызовов, потом источник отвечает. Так проверяются повторы адаптера: `error:1` — первая попытка падает, вторая проходит;
- `ok` — источник всегда отвечает, даже при включённых случайных сбоях.

Пример: ФССП не отвечает, а ЕГРЮЛ отвечает только со второй попытки:

```bash
MOCK_SOURCES_SCENARIOS='{"5406000001": {"fssp": "timeout", "egrul": "error:1"}}'
```

### Воспроизводимость

Каждый вызов разыгрывается из своего потока случайных чисел: зерно мира, ИНН, источник и номер вызова для этой пары. Поэтому одна и та же последовательность вызовов даёт одни и те же задержки и сбои при каждом запуске. Повторная попытка — это следующий номер вызова, поэтому после сбоя она может пройти. `reset()` обнуляет счётчики вызовов.

Случайные сбои по умолчанию выключены. Сбой ФНС или ФССП меняет решение (флаг и штраф к оценке, SPEC §5), а одинаковые входы должны давать одинаковый результат. Сбои для демо задаются сценариями.

## Что нужно следующим задачам

- **T07 (адаптеры и оркестратор):**
  - сервис отдаёт только `payload`; конверт `SourceResponse` строит адаптер;
  - таймаут 10 с и повторы — тоже на стороне адаптера: сервис при таймауте висит 15 с и сам не обрывается;
  - адаптер может звать сервис в процессе (`fetch`) или по HTTP. Во втором случае роутер нужно подключить в `apps/api/main.py` — это файл трека 2, поэтому подключение согласуется с его владельцем;
  - `SourceNotFound` у ЕГРЮЛ значит «такой компании нет». Что делать с ним у остальных источников, решает политика отказов T07.
- **T12 (персоны):** сценарий для персоны (например, ФССП не отвечает) задаётся в `MOCK_SOURCES_SCENARIOS`, мир при этом не меняется.
- **T34 (Docker):** переменные `MOCK_SOURCES_*` и `WORLD_*` есть в `.env.example`. Чтобы API не строил мир при каждом старте, мир можно записать в `apps/world/out` при сборке образа.

## Упрощения

В коде помечены `# MOCK:` и `# SIMPLIFICATION:`.

| Упрощение | Как было бы в реальности |
|---|---|
| Все источники отвечают из одного синтетического мира, по ИНН компании | Каждая интеграция — свой протокол (СМЭВ, API БКИ, выгрузки ФССП и картотеки арбитражных дел), свои форматы и авторизация |
| Ответы урезаны до полей контракта (SPEC §5) | Настоящие ответы ЕГРЮЛ, ФНС и БКИ намного шире |
| Задержка не зависит от нагрузки и времени суток; частоты сбоев — оценка | Задержки и доступность по SLA и мониторингу каждой интеграции; сбои идут сериями |
| Ошибка источника одна на всех — `SourceUnavailable` | Разные коды ошибок: нет согласия, превышен лимит запросов, неверный запрос, техническая ошибка |
| Запрос в БКИ не оставляет записи о запросе нашего банка в отчёте | Каждый запрос попадает в кредитную историю субъекта |
| Ответы не кешируются и не тарифицируются | Запросы в БКИ платные, их кешируют на срок действия согласия |
