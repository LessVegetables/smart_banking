# Mini app

Мобильная оболочка использует общий React-клиент, компоненты заявки и API. Точка входа — `/mini/`; определение оболочки и интеграция Telegram находятся в `apps/web/src/main.tsx`. Это позволяет использовать одну версию клиентского пути и компонентов без двух расходящихся копий интерфейса.

В обычном браузере доступен демо-вход. В Telegram загружается официальный Web App SDK и отправляется `initData` для серверной HMAC-проверки. Сервер проверяет срок действия 5 минут. Для запуска через бота настройте `TELEGRAM_BOT_TOKEN`, `APP_ORIGIN` и HTTPS-адрес `/mini/` в меню бота. В production установите `COOKIE_SECURE=true`.
