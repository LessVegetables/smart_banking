# Документация «Альфа · Бизнес»

Документация прототипа кредитного конвейера для малого и микробизнеса.

**Демо:** [etabank.ru](https://etabank.ru/) · **Документация:** [docs.etabank.ru](https://docs.etabank.ru/)

Начните с [полной карты документации](docs/README.md), чтобы выбрать маршрут по роли. Для быстрого запуска откройте [руководство](README.md); для кредитной логики — [спецификацию v2](docs/v2/SPEC.md).

## Что здесь описано

- клиентский кабинет и рабочее место сотрудников;
- путь заявки от ввода потребности до подписания и демонстрационной выдачи;
- синтетический мир, моки источников, признаки, скоринг и кредитная политика;
- API, контракты данных, статусы, ручная обработка, эксплуатация и ограничения.

Все данные и внешние ответы в прототипе синтетические. Документация не описывает реальные банковские продукты, тарифы или интеграции.
