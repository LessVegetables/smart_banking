# Реестр упрощений и моков

Всё, что в прототипе сделано иначе, чем в банке. В коде такие места помечены `# MOCK:` (имитация внешней системы) или `# SIMPLIFICATION:` (упрощённая логика); `git grep -nE "(#|//) ?(MOCK|SIMPLIFICATION):"` находит все. Подробные таблицы по компонентам — в их документации, ссылки в каждом разделе; здесь собрано главное.

Общие упрощения уровня спецификации — SPEC §15: внешние источники — моки, фондирование — константа, LGD — таблица, комитет — две подписи, подписание — кодом в интерфейсе, залог и гарантия МСП — моки, выдача — мок, после выдачи ничего нет, модель обучена на синтетике.

## Внешние системы

Интеграции с реальными системами запрещены условиями кейса, поэтому каждая внешняя система — мок внутри проекта за адаптером, который можно заменить настоящей интеграцией.

| Упрощение | Где | Как было бы в реальности |
|---|---|---|

| `# MOCK:` задержки моков — в диапазоне примеров T00, частоты сбоев — оценка | `apps/sources/service.py` | Задержки и доступность по SLA и мониторингу каждой интеграции; сбои идут сериями |

## Синтетический мир

Реальные данные запрещены условиями кейса. Мир генерируется из зерна; все упрощения генератора с описанием реальности — таблица «Упрощения» в [apps/world/README.md](../apps/world/README.md). Главные:

| Упрощение | Как было бы в реальности |
|---|---|
| 12 отраслей с параметрами, заданными вручную; выручка — логнормальная вокруг медианы отрасли | Полное дерево ОКВЭД, распределения по данным банка |
| Вероятность дефолта зависит только от скрытого качества `q`, отрасли и архетипа; исход есть у каждой компании, как будто банк выдал кредит всем | Исходы только по выданным кредитам, дефолт вызывают и события после выдачи |
| Доли мошеннических архетипов фиксированы, у компании не больше одного архетипа | Доля мошенничества неизвестна и меняется |
| Затраты — постоянные доли выручки, налоги — плоская ставка по режиму; наличная выручка не попадает на счёт | Реальная структура затрат, НДС, вычеты, сроки уплаты |
| В БКИ у собственника только карты и потребительские кредиты; проверяется только основной учредитель; связанных компаний нет | Ипотека, поручительства, отчёты по всем значимым учредителям, группы компаний |
| `# MOCK:` мир — снимок на дату среза (`WORLD_AS_OF`), поэтому признаки считаются на эту дату, а не на дату ответа источников (`apps/api/workflow.py`) | Признаки на дату ответов источников |
| Выписки из других банков (T12): один выдуманный банк; клиент с недавно открытым счётом перевёл к нам весь бизнес сразу (`apps/world/statements.py`) | Выписки разных банков в своих форматах; переход клиента растягивается на месяцы |
