# Соответствие архитектуре

| Компонент | Реализация |
|---|---|
| Два клиентских продукта | Веб `/` и мобильная оболочка `/mini/`, общая библиотека React-компонентов |
| Общий backend | FastAPI, типы запросов Pydantic, опубликованная OpenAPI-схема |
| Продукты и политика | `config/rules.json`; снимок политики сохраняется при подаче и используется повторно worker и андеррайтером |
| Опрос | `apps/api/catalog.py`: 43 вопроса, серверная валидация, активные ветки, очистка скрытых ответов, история |
| Расчёты | Чистые функции `engine.py`, отдельные модели аннуитета и линии, причины и вклад факторов |
| Заявки | SQLAlchemy-модели, атомарная запись переходов, контроль версии, ключи идемпотентности |
| Фоновые задания | Таблица jobs, условный захват задания, аренда и восстановление, ограниченные повторы |
| Документы | Закрытые локальный/S3 адаптеры; доступ через API после проверки владельца |
| Подтверждение финансов | Сотрудник проверяет документы и вводит подтверждённые значения; старые решения сохраняют прежние входные данные |
| ИИ | Необязательный Responses API, минимальный контекст, справочный fallback, отсутствие инструментов изменения заявки |
| Авторизация | Изолированные демо-кабинеты, серверные cookie-сессии, HMAC Telegram, отдельный пароль сотрудника |
| Сквозная история | Сохранённые переходы, запускавшие их действия, комментарии, снимки решений и правил |
| Обновления статуса | Клиенты опрашивают API; реальные внешние сообщения не отправляются |

## Демонстрационные параметры, отсутствовавшие в TXT

- Условные ставки: оборотный 24%, оборудование 21%, линия 25% годовых.
- Минимальный срок линии: 3 месяца. Полная выборка лимита; равномерное погашение основного долга и проценты на остаток.
- Стоимость обеспечения ограничивает инвестиционную сумму коэффициентом 70%.
- Возраст: менее 6 / 12 / 24 месяцев → +30 / +20 / +10 баллов.
- Долг/выручка: до 20 / 40 / 60 / 80% → 0 / 10 / 20 / 35 баллов.
- Запрос/выручка: до 15 / 30 / 40 / 50%, выше → 0 / 10 / 20 / 30 / 40 баллов.
- Динамика: рост −5, стабильность 0, снижение +25; нет кредитной истории +10, обороты в Альфе −10.
- Срок предложения: 7 дней. Сумма округляется вниз до 1 000 ₽.
- Синтетический справочник ОКВЭД: префикс 92.1 — стоп, 64.9 — ручное рассмотрение. Это исключительно условия демонстрации, не банковские ограничения. Срок бизнеса вычисляется сервером из даты регистрации.
- Просрочки до 5 дней и незначительные по сумме исключаются. 90+ дней в окне 36 месяцев — стоп-фактор; старые 61–89 дней начисляют баллы согласно политике.
- Три значимых эпизода за последний год устанавливают минимум высокого риска.

Параметры нужны для согласованной демонстрации, не основаны на реальных банковских тарифах. При расширении политики меняются версия и тесты.

## Подготовленные, но не проверенные внешние подключения

Telegram требует действующего токена бота и HTTPS; модель — собственного API-ключа и имени модели; S3 — закрытого бакета и credentials. PostgreSQL/Compose требуют Docker. Локальная версия работает без этих внешних зависимостей на SQLite и файловом адаптере.

## Следующий промышленный этап

Интеграции реестров/БКИ; реальные проверки реквизитов и обеспечения; полноценная идентификация и роли участников компаний; миграции БД; долговременные коды привязки; объектная антивирусная проверка; OCR с подтверждением; наблюдаемость и доставка уведомлений; ЭП и банковский контур выдачи. Локальная демонстрация не имитирует наличие этих подключений.
